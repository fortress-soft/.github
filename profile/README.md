# Fortress Software Solutions

Fortress Software Solutions (FSS) is an independent software studio in Athens, Greece, run by Evangelos Panos. FSS designs, builds and runs software for small businesses: full-stack web platforms with staff and client apps, fast bilingual websites, and self-hosted tools that are tested, containerised and deployed through CI.

## Client work

- **[BalanceLab](https://balancelab.gr)**: a practice-management platform for a dietitian practice. It includes a staff app, a client portal, a public website and an Android tablet app, all served by one Spring Boot API. This is a private client project.
- **[elenas-houses.com](https://elenas-houses.com)**: a bilingual (English/Greek) website for short-stay apartments in Athens. It was moved from WordPress to a fast static React site with prerendered pages.
- **[scs-security.gr](https://scs-security.gr)**: a responsive Greek website for an alarm and CCTV installer, with a working contact form.
- **Battle Arts Academy**: a responsive Greek one-page website for a martial-arts academy in Kifissia.

## Own products

- **[Meadhall Character Builder](https://github.com/fortress-soft/meadhall)** (open source): a self-hostable, multi-user server edition of the Borealis D&D 5e character builder. It adds accounts and parties, a DM combat and encounter tracker, a spell engine and bring-your-own-AI assistant tools over MCP. It ships as a Docker image and as Android, iOS and desktop builds. Built with Rust (Axum, sqlx), React/TypeScript and Tauri 2.
- **ProveYourLag** (in development): a network-latency evidence tool for gamers on Windows, Linux and Docker. It records latency before, during and after a lag spike and exports PDF, CSV and JSON reports that can be shared with an ISP.

## Open-source contributions

- **[TeamBorealis/borealis](https://github.com/TeamBorealis/borealis)**: four merged fixes for sheet layout, import add-on grants, AI tool detection on non-Unix systems, and ASI/Feat placeholders.
- **[xpengtoolkit/xpengtoolkit](https://github.com/xpengtoolkit/xpengtoolkit)**: six merged pull requests for this Home Assistant integration for XPENG vehicles, covering remote-command fixes, stateful climate, window and seat controls, a custom Lovelace vehicle card, and charging-current fixes.

## Stack

- **Backend:** Java and Spring Boot (Security, Data JPA, Flyway), Rust (Axum, Tokio, sqlx), Python
- **Frontend and apps:** React, TypeScript, Vite, TanStack Query, PWA, Capacitor (Android), Tauri 2
- **Data:** PostgreSQL, SQLite
- **Quality:** JUnit and Testcontainers, Vitest, Playwright, ArchUnit, Error Prone and NullAway
- **Delivery:** Docker and Docker Compose, GitHub Actions, GHCR, nginx
